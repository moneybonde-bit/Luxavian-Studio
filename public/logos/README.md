# Logo Luxavian

Unggah file logo resmi ke folder ini dengan nama persis:

```
public/logos/luxavian-logo.png
```

Setelah file ada, logo otomatis tampil di navigasi dan footer
(path dikonfigurasi di `src/config/site.js` → `SITE.logo`).

Selama file belum ada, situs menampilkan wordmark teks "LUXAVIAN. DIGITAL STUDIO"
sebagai fallback — tidak akan muncul ikon gambar rusak.

Rekomendasi: PNG transparan, rasio 1:1, minimal 160×160 px.

# Thumbnail Portfolio

Letakkan gambar thumbnail proyek di folder ini, lalu daftarkan path-nya
di `src/data/projects.js` (field `thumbnail`), contoh:

```
/images/portfolio/wedding-invitation.jpg
```

Jika gambar belum ada atau gagal dimuat, kartu portfolio otomatis
menampilkan placeholder gradien.

Rekomendasi: rasio 16:9 (mis. 1280×720 px), format JPG/WebP, ukuran < 300 KB.
